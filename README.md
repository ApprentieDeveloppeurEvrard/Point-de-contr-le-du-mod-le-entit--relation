# Modèle Entité-Relation – Gestion d'une Salle de Sport

Ce projet propose un modèle conceptuel pour gérer les inscriptions, les coachs et les séances dans une chaîne de gymnases.

## 📌 Contexte

Le système permet de gérer :
- Plusieurs gymnases
- Des membres avec leurs inscriptions aux séances
- Des coachs qui animent les séances
- Des séances limitées à 20 membres, et animées par un maximum de 2 coachs
